EXEMPLO 1: Chamado Urgente de Infraestrutura
====================================================================
Atendimento emergencial realizado para a empresa TechFin Soluções.
Durante a madrugada, o servidor principal de banco de dados sofreu uma queda por falta de espaço em disco, afetando a API de pagamentos.
A equipe de infraestrutura realizou a limpeza de logs e o upgrade do volume de armazenamento na nuvem.
O serviço foi totalmente restabelecido e a ordem de serviço foi fechada com status Concluído.
Valor total das horas extras e suporte técnico: R$ 2.800,00. Prioridade tratada como Alta.

====================================================================

EXEMPLO 4: Desenvolvimento de IA / Automação
====================================================================

O projeto envolve a criação de pipelines em Python e banco de dados SQLite para gravação dos históricos.
Atualmente o projeto está Em Andamento e a prioridade do cliente é Alta para entregar antes do final do trimestre.
Valor do contrato de desenvolvimento: R$ 12.000,00.
